وهذا هو السبب الجذري للثغرة الحرجة F1 — سلسلة سببية كاملة:
1. التعليق يأمر المشغّل بوضع VITE_REPORTS_API_KEY في .env.
2. البناء الحديث يرفض ذلك (فحص الـ sentinel)، فيبدو للمشغّل أن "المتغيّر يكسر البناء".
3. النتيجة: المتغيّر لم يُضبط أبدًا.
4. وmockApiService.cjs:49 يقرأ VITE_REPORTS_API_KEY من ملف .env الجذري نفسه بوصفه المصدر الوحيد لـ REPORTS_WORKER_KEY.

تعاضد في الأسماء يضاعف الخطر: نفس الاسم VITE_REPORTS_API_KEY له غرضان متناقضان في نفس الملف — "سر يجب ألا يُخبز" (منظور البناء) و"مفتاح يقرأه الديسكتوب" (منظور المزامنة). أي تدوير أو تحديث للسر سيقع في هذا الفخ مجددًا.

F19 منخفض — تعريفان مختلفان لصافي الربح بين الديسكتوب والبوابة

الموقع: src/utils/reportMath.ts:36 مقابل reports-site/src/analytics.ts:221
// reportMath.ts:36 — الديسكتوب يفرض أرضية صفر
export function computeNetProfit(revenue, taxAmount, cogs) {
  return Math.max(0, roundMoney(revenue - taxAmount - cogs));   // لا يعرض خسارة أبدًا
}

// analytics.ts:221 — البوابة لا تفرض أرضية
const netProfit = revenue - tax - cogs;                          // قد يكون سالبًا

التحليل: فترة خاسرة (مثلاً تكلفة مكوّنات أعلى من سعر البيع) ستُعرض في تطبيق الكاشير كـ 0، وفي بوابة المدير كـ رقم سالب. تعليق reportMath.ts يبرّر ذلك: "رقم سالب على بطاقة ربح يُقرأ كمشكلة في البيانات لا كخسارة" — لكن النتيجة أن المدير والكاشير يريان ربحًا مختلفًا لنفس اليوم، ولا يوجد أي مؤشر على الشاشة يفسّر الفرق.

فرقٌ ثانٍ في نفس النمط: analytics.ts:214 يجمع الضريبة من order.taxAmount، بينما reportMath يستقبل taxAmount محسوبًا من طرف المستدعي — أي أن المرجع الوحيد هو اللقطة المخزّنة مع الطلب، وهو صحيح، لكنه يعني أن أي صف قديم بلا لقطة ضريبية يُحسب بصفر ضريبة (toNum(null) → 0) فيُضخِّم الربح الصافي.

الإصلاح

// AFTER — عرّف المصدر مرة واحدة وشاركه (cloudflare/shared/money.js أو utils/orderTotals)
export function netProfit(revenue: number, tax: number, cogs: number): number {
  return roundMoney(revenue - tax - cogs);           // قيمة واحدة، بلا أرضية
}
// العرض يقرر: بطاقة الكاشير تعرض max(0, value) + وسم "خسارة" عند السالب،
// والبوابة تعرض القيمة الحقيقية. قرار العرض لا ينتمي إلى طبقة الحساب.

// AFTER — ارفض الصفوف بلا لقطة ضريبية بدل حسابها صفرًا
orderTax(order) {
  const t = Number(order.taxAmount);
  return Number.isFinite(t) ? roundMoney(t) : null;   // null = "مجهول"، يُعرض للمدير
}
